# GProj (Temp Name) DESCRIPTION

## GProj is a group management application designed for student group projects. Our goal is to offer features to help students with their projects such as boards to display project workflows, planners for scheduling, and labeling to represent indivdual tasks and ideas. These are just a few of the many features that GProj contains and we are always expanding. Find out how to use GProj in the learnhow file!
